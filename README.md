# Saude_hospital.py
 
Sistema Integrado de Saúde – Uíge

O Sistema Integrado de Saúde do Uíge é um programa desenvolvido em Python com o objetivo de facilitar o registo de pacientes, unidades de saúde e consultas médicas, permitindo organizar o histórico clínico e melhorar a coordenação dos serviços de saúde.

Principais funcionalidades

1. Registar e listar unidades de saúde.
2. Cadastrar pacientes através do número do BI.
3. Registar consultas médicas.
4. Armazenar diagnósticos e tratamentos.
5. Consultar o histórico clínico dos pacientes.
6. Gerar relatórios de consultas por unidade.
7. Contabilizar o total de pacientes.
8. Evitar registos duplicados de pacientes e unidades.
9. Facilitar a organização e coordenação dos serviços de saúde.

Tecnologias utilizadas

- Linguagem de programação: Python.
- Estruturas de dados: Listas e dicionários.
- Interface: Menu interativo no terminal.

Unidades de saúde iniciais

- Hospital Provincial do Uíge.
- Centro de Saúde de Sanza Pombo.

Como executar

1. Instalar o Python.
2. Abrir o terminal.
3. Executar o ficheiro "sistema_saude.py" com o comando:

python sistema_saude.py

Objetivo final

Melhorar a organização das informações dos pacientes, facilitar o acompanhamento clínico e apoiar a coordenação dos serviços de saúde na província do Uíge.

Nota: Esta versão armazena os dados temporariamente, perdendo-os quando o programa é encerrado.
